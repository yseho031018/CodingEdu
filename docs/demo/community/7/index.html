CSS Flexbox 완전 정복 - 레이아웃 잡기 이제 쉽습니다

프론트깎는노인 2026-10-17 14:04
👁️ 158
Flexbox는 처음엔 헷갈리지만 제대로 이해하면 레이아웃이 정말 쉬워져요! **기본 설정** ```css .container { display: flex; flex-direction: row; /* 가로 정렬 (기본값) */ } ``` **자주 쓰는 패턴** ```css /* 완전 중앙 정렬 */ .center { display: flex; justify-content: center; /* 가로축 */ align-items: center; /* 세로축 */ } /* 양 끝 정렬 */ .space-between { display: flex; justify-content: space-between; } ``` **flex-grow vs flex-shrink** - `flex-grow`: 남은 공간을 얼마나 차지할지 - `flex-shrink`: 공간 부족 시 얼마나 줄어들지 - `flex: 1`이면 `flex-grow: 1; flex-shrink: 1; flex-basis: 0` Grid와 함께 쓰면 대부분의 레이아웃을 처리할 수 있어요! 🎨
