# simulation Game

알바 생존기 기반의 자취/알바/주식 모의 시뮬레이션 게임입니다.

## 실행 방법

브라우저에서 `index.html`을 열면 바로 실행됩니다.

GitHub Pages를 사용할 때는 저장소 루트의 `index.html`이 자동으로 `alba-survival-game/`으로 이동시킵니다.

## 주요 기능

- WASD 또는 클릭 이동
- 현관문에서 출근하기
- 대중교통/택시 출근 선택
- 편의점, 카페, PC방, 음식점 알바 맵
- 일일 알바 퀘스트와 퇴근 정산
- 사장님 평점, 손님 평점, 멘탈, 체력 관리
- 자취자금, 월세/관리비, 방 구하기 체크리스트
- 핸드폰 UI
- 토스 계좌 화면
- 국내/해외 주식 모의 거래
- 주식 1만원 매수, 올인 매수, 전량 매도
- 휴무일 추천 루틴과 다음날 넘기기

## 참고

주식은 실제 증권 거래가 아닌 게임 안 모의 거래입니다.
